# NEXORA — نيكسورا: عوالم متحدة

لعبة Android مبنية على Godot 4.3، بواجهة عربية RTL افتراضياً ودعم الإنجليزية LTR. الإصدار المستهدف في هذا التغيير: **0.10.0 (version code 17)**، ومعرّف الحزمة `com.nexora.worlds`.

## أنظمة بطاقات الحظ — 0.10.0

- خمس درجات معلنة: عادية 68%، نادرة 22%، مميزة 7%، أسطورية 2.5%، فريدة 0.5% (المجموع 100%).
- احتمال ظهور البطاقة منفصل عن ندرتها: انتصار عادي 25%، انتصار نخبة 100%، زعيم منطقة 100% مع اختيار واحدة من ثلاث، مهمة خاصة 100%، صندوق عادي/موسم 20%، ذهبي 35%، زعيم 55%.
- ضمانات مستقلة بعد 10 / 30 / 70 / 150 كشفاً دون الدرجة المطلوبة. تُحتسب عند كشف بطاقة حظ فعلي فقط، وتُعرض الاحتمالات المعدّلة عند تفعيل الضمانة.
- 13 بطاقة ببيانات القوة والميزة والجانب السلبي، مع حفظ المجموعة والعدادات وسجل آخر 20 كشفاً محلياً.
- هزيمة زعيم المنطقة ترفع تقدم المهمة اليومية الخاصة؛ استلامها يمنح بطاقة حظ مضمونة.

## المنصة والحفظ

- Android ARMv7 وARM64.
- الحفظ محلي داخل مساحة التطبيق مع نسخة احتياطية وترقية مخطط الحفظ إلى الإصدار 10.
- صلاحية الإنترنت معطلة في نسخة Android الحالية.
- لا توجد مقامرة أو رهانات أو جوائز نقدية أو شراء عشوائي بأموال حقيقية.
- لا يوجد حالياً ربط Google Play Games أو حساب سحابي أو AdMob أو Play Billing؛ هذه تكاملات مستقبلية وليست مزايا مفعّلة.

## البناء والتحقق

يشغّل GitHub Actions استيراد Godot، اختبارات الحفظ والأنظمة، تشغيل المشهد الرئيسي، تصدير APK والتحقق من توقيعه. ملف APK الناتج حالياً Debug وموقّع بمفتاح مؤقت؛ لا يصلح كتحديث فوق إصدار Release موقّع بمفتاح مختلف. كما أن نجاح CI لا يعني اختبار التثبيت على هاتف فعلي.
