# NEXORA — نيكسورا: عوالم متحدة | v1.0.0

لعبة Android مبنية على Godot 4.3، بواجهة عربية RTL افتراضياً، وتجربة هاتف أولاً. تعمل حالياً دون اتصال وتحفظ التقدم محلياً على الجهاز.

## أنظمة السحب وبطاقات الحظ

- فرصة ظهور بطاقة حظ في السحب العادي: **18.5%**؛ أما العملات والجواهر فلها جدول مكافآت مستقل معلن.
- ندرة البطاقة عند ظهورها: عادية **68%**، نادرة **22%**، مميزة **7%**، أسطورية **2.5%**، فريدة **0.5%**.
- ضمانات مشتركة عند كشف بطاقة فقط: نادرة+ بعد **10** إخفاقات، مميزة+ بعد **30**، أسطورية+ بعد **70**، وفريدة بعد **150**.
- عدادات الضمان مشتركة بين السحب والصناديق؛ مكافآت العملات والجواهر لا تحركها.
- فرص ظهور بطاقة من الصناديق: العادي **20%**، الذهبي **35%**، الزعيم **55%**، الموسم **35%**.
- تمت إضافة 5 بطاقات جديدة و19 بطاقة إجمالاً، مع القوة والقدرة والأثر السلبي لكل بطاقة.
- أوصاف القدرات والسلبيات ظاهرة في المجموعة؛ تجهيز البطاقات وتطبيق تأثيراتها الفعلية على القتال ما زال ضمن العمل التالي.

## الحفظ والخصوصية

- مخطط الحفظ المحلي v10 مع أربع عدادات ضمان مستقلة.
- ملفات v9 القديمة تُرحّل دون فقدان العملات أو البطاقات أو تقدم الموسم؛ يبدأ نظام الضمان الجديد من الصفر لأن عداد v9 القديم كان يحسب السحبات لا كشوف البطاقات.
- لا يوجد اتصال أو حساب أو إعلانات أو شراء بأموال حقيقية في هذا الإصدار.
- لا توجد مقامرة أو رهانات أو جوائز نقدية.

## بناء Android

1. افتح GitHub Actions.
2. شغّل **Build NEXORA Android APK** أو ادفع تغييراً إلى `main`.
3. انتظر استيراد Godot والاختبارات وتشغيل المشهد وتصدير APK والتحقق من التوقيع.
4. نزّل artifact باسم `NEXORA-v1.0.0-Android-Debug-APK`.

Package ID: `com.nexora.worlds` — Version: `1.0.0` — Version code: `17`.

## ما لم يكتمل بعد

- ربط ظهور البطاقات بانتصارات الحملة والمهام الخاصة.
- نظام تجهيز البطاقات وتطبيق قدراتها وسلبياتها في القتال.
- استبدال شبكة الأنماط القديمة بتبويبات التصميم الخمسة النهائية.
- اختبار التثبيت على هاتف فعلي ومفتاح توقيع Release دائم.
- تسجيل Google Play والمزامنة السحابية وخدمات الإعلانات/الفوترة غير مدمجة.
